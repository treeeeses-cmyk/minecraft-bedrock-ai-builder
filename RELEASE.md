### Installation

1. Download the repository as ZIP
2. Extract files
3. Run `npm install`
4. Add your OpenRouter API key to `.env`
5. Run `npm start`

### Quick Start

```bash
npm install
cp .env.example .env
# Edit .env with your API key
npm start
```
