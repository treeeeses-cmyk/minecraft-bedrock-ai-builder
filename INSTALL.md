# Installation Guide - Готовое к использованию

## Способ 1: Скачать готовый аддон (Самый простой)

### Windows/Mac/Linux

1. **Скачайте файл аддона напрямую:**
   - Перейдите в репозиторий: https://github.com/treeeeses-cmyk/minecraft-bedrock-ai-builder
   - Нажмите на зелёную кнопку **"Code"**
   - Выберите **"Download ZIP"**
   - Распакуйте файл

2. **Установите аддон в Minecraft:**
   - Найдите файл `minecraft-ai-builder.mcaddon` в папке
   - Двойной клик на файл
   - Minecraft автоматически установит аддон
   - Готово! ✅

## Способ 2: Использовать через Node.js (Для разработчиков)

```bash
# 1. Скачайте проект
git clone https://github.com/treeeeses-cmyk/minecraft-bedrock-ai-builder.git
cd minecraft-bedrock-ai-builder

# 2. Установите зависимости
npm install

# 3. Запустите
npm start
```

## Что нужно?

- ✅ Minecraft Bedrock Edition (Windows 10/11, Xbox, или мобильный)
- ✅ Интернет соединение
- ✅ API ключ **уже включен** в аддон!

## Решение проблем

### "Файл не найден"
- Убедитесь, что скачали весь репозиторий
- Проверьте папку загрузок

### Minecraft не открывает .mcaddon
- Убедитесь, что у вас установлена **Bedrock Edition** (не Java)
- Скачайте с [официального сайта Microsoft](https://www.minecraft.net/download)

### API ошибка
- API ключ уже настроен
- Проверьте интернет соединение

## Готово к использованию!

После установки в Minecraft используйте команду:
```
/build создай современный дом
/build построй замок
/build сделай ферму
```
